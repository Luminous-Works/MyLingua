MyLingua

Hold the microphone, speak, release. Hear a natural translation between Spanish and English.

MyLingua is an Android app. It transcribes your speech on the device, translates it with Gemini through Firebase AI Logic, and reads the translation aloud.

Download the test APK Source code (Apache-2.0)

Test it

  1. Install the APK on an Android 7.0 (API 24) or later device. You may need to allow installs from your browser or file manager.
  2. Grant microphone access when asked.
  3. Hold the microphone and say something in English. Release. The Spanish translation appears and is spoken.
  4. Tap Español, then hold the microphone and speak Spanish. The English translation appears and is spoken.

This is a debug test build. Gemini calls are protected by Firebase App Check, which only accepts registered devices. If the translation fails on your device, open an issue on the GitHub repository with the debug token from Logcat (tag DebugAppCheckProvider) and it will be registered.

How it works

  • Listen: Android SpeechRecognizer, with live partial results.
  • Translate: Gemini (gemini-2.5-flash) through Firebase AI Logic, with an interpreter system instruction for natural, grammatical output.
  • Speak: Android TextToSpeech, using the best voice for the target language.
